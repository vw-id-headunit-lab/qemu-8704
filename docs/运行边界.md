# 运行边界

## 当前工程定位

主路线是 Apple Silicon macOS + QEMU HVF 承载原厂用户空间；原生 Linux、Android、QNX/IC/HUD 路线另有各自的执行、身份和画面来源验证。Windows 入口保留为历史工程预览，不能声称与 macOS 功能等同。

## 不得混淆的结果

- `doctor` 成功、输入哈希一致、QEMU 运行或域标志 RUN，不代表原业务应用持续运行。
- 原内核命令能执行，不代表 Android framework、服务注册、`boot_completed` 或业务页面完成启动。
- 历史截图、录制帧、真实帧龄及局部 PBO 读回，不是持续动态刷新或完整最终扫描面。中控、Android、IC、HUD 必须保持独立来源与会话归属。
- 地图文件完整、原导航服务启动或旧截图存在，不等于导航入口、搜索、路线规划和全部触摸交互通过。
- 本机已有输入可运行，不等于新机器只克隆仓库即可运行；仍需合法输入、依赖、路径绑定和实际冷启动验证。

## 功能与安全约束

整体目标未全部验收。完整 Android framework、原生显示完整性、全导航业务、空调交互和长期稳定性不得从局部测试推导为完成。实车采集快照、本地模拟 RSI、虚拟定位和点火输入必须与实时实车信号明确区分。

保持原固件、地图许可、认证、原电源生命周期、自动休眠和看门狗的边界；不伪造 HMIReady、ALIVE、同步完成或 `boot_completed`，不绕过身份、安全硬件或原厂激活。观察超时不构成重启或放宽门控的理由。

## 资源与发布

原始 8704 包、镜像、地图、原厂 JAR、个人车辆配置和运行快照不提交 Git。大型资源单独打包，由用户自行管理；网盘上传完成并提供链接后才更新 README。资源包本身不构成重新分发授权。

历史会话和过程文件清理不改变功能验收状态。只删除确认不被运行、当前状态、种子或 backing 链引用的产物；必要盘和活动文件保留。清理前后的同输入检查、原始退出状态、文件哈希及回滚记录保存在项目外清理档案，研究证据与用户指南分离。
