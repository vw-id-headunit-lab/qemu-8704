# 目录结构与清理规则

## 保留的项目内容

- `src/`：平台模型、适配器、客体启动脚本及其运行所需载体。
- `tools/`、`tests/`：维护命令与回归测试；不把未提交的新源码或测试视为垃圾。
- `native/`、`runtime/`、`config/`：原生覆盖源码、锁定上游输入、已验证运行载体与配置。
- `docs/`、`licenses/`：使用、开发、Mac 运行、发布状态、运行边界和许可证。

## 本地数据，不进入发布包

- `var/inputs/`：原始固件、派生镜像、种子、实车导出 ZIP 及其采集说明。不得因为体积大而删除。
- `var/hvf/`：当前会话、控制状态及可写盘；`var/sessions/` 中被种子清单引用的基线也需保留。
- `var/screenshots/reference-20261124/`：从根目录归档的六张历史参考图，原始字节不变；其中 `surface-16.png` 实际是 BMP，沿用原名以维持溯源，不冒充实时帧。
- `8704/`：已有的私有更新包提取目录；为避免破坏外部和历史引用，本次保持原路径。
- `.venv/`、`.local/deps/`、`.local/build/`：本机依赖和构建工具；当前 `qemu_data` 仍引用构建树的 `pc-bios`，不能整体删除。
- `.local/mac-port/status.json`、`transaction/`、`logs/`：当前检查点、原有验证回滚角色和构建日志；保留现有路径。新近工作目录也不清除。

## 清理边界

只有同时不被活动进程、打开文件、当前状态、镜像 backing chain 或种子依赖引用的历史会话才可移除。旧截图和用户投入的原始资料优先归档，不重编码、不改原包；已结束的运行产物、一次性研究脚本和可再生缓存从工作树移除。不要使用 `git clean -fdx` 或按未跟踪状态批量删除。
