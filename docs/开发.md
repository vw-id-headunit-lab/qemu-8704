# 开发与构建

## 结构

- `src/emu/`：平台模型、介质处理、图形转发和运行服务。
- `src/runner/`：三系统调度入口及相关采样代码。
- `src/firmware/`：固件格式解析代码；不存放固件。
- `runtime/`：一个 ARM64 系统模拟器、一个图形宿主及自有客体转发库。
- `native/upstream/`：固定版本 QEMU 原始源码归档。
- `native/overrides/`：对应的修改及新增源码。
- `tools/`：统一命令、依赖安装、校验与打包。

## 校验

`config/release-manifest.json` 固定公开文件的 SHA256。修改源码后运行 `python tools/emu.py freeze` 更新清单，再运行统一入口的 `verify` 和 `test`。不要将私有输入加入清单。

```powershell
./MEB-EMU.ps1 test
./MEB-EMU.ps1 verify
```

## 原生源码

上游归档为 QEMU 11.1.0，SHA256：`6ee1d1a61f68212476b27108c26da5f449dc09b626d42f8279ba0dc2e08fa858`。准备源码时解开归档，再用 `native/overrides/` 中同路径文件覆盖。编译使用 Windows MSYS2 MinGW64，目标 `aarch64-softmmu`。

```powershell
./.venv/Scripts/python.exe -X utf8 -B tools/native_sources.py
```

命令生成 `.local/build/qemu-11.1.0/`，仅跳过上游指向主机外部目录的 X11IncludeHack 符号链接（Windows 目标不使用该文件）；完整上游归档保持原字节。在 MinGW64 终端执行配置和构建：

```sh
mkdir -p .local/build/native
cd .local/build/native
../qemu-11.1.0/configure --target-list=aarch64-softmmu --disable-werror --prefix=/BUILD_ROOT
ninja qemu-system-aarch64.exe
```

公开二进制已剥离调试信息，并用 `tools/sanitize_pe.py` 规范只读数据节中的构建路径。模拟器另外只规范一处地址重定位比较的两个路径立即数，工具要求完整指令签名唯一匹配，保留指令操作码、长度和文件布局；不改模拟逻辑。客体 ELF 只去除非装载的调试节。图形宿主与客体库的构建脚本位于 `src/emu/gl-forward/`；宿主编译器使用 `CC` 或 PATH 中的 gcc，客体使用 `ZIG` 或 PATH 中的 zig（原构建版本 0.15.2）。ANGLE 开发头文件和导入库由 `EMU_ANGLE_SDK` 指定，默认 `.local/angle-sdk/`，不要求另一个研究工作区。
